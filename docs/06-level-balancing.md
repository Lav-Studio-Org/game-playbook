# 06. Desain level dan balancing lewat simulasi

Pelajaran terbesar LETUP! v1.1 -> v1.2: kesulitan yang ditebak terasa acak. Bintang 3 di level 1-10 ternyata **0%** (mustahil), sementara di level akhir justru lebih mudah. Setelah semua angka dihitung dari simulasi, kurva jadi mulus dan bintang 3 bab 1 naik ke 30%.

## Syarat: logika murni yang bisa dijalankan headless

`js/engine.js` harus bisa: `createWorld(cfg)`, `tap/move(world, ...)`, `step(world, dt)`, `won(world)`, `stars(world)`, tanpa DOM, dengan RNG ber-seed. Lihat [01-stack-struktur.md](01-stack-struktur.md).

## Langkah

1. **Bot yang mirip pemain.** Bukan acak murni. LETUP!: dari 12 titik acak pilih yang paling banyak gelembung dalam jangkauan ("ketukan terarah"). Onet: pilih pasangan valid secara acak. Suika: jatuhkan di dekat bola dengan angka sama.
   - `scripts/sim.js` mengekspor `attempt(cfg, rng, aim)` yang memainkan satu percobaan.
2. **Audit dulu.** `scripts/audit-*.js` menjalankan N percobaan per level / bab dan mencetak tabel peluang menang / bintang 2 / bintang 3. Simpan tabel "sebelum" di `docs/LEVEL_DESIGN.md`.
3. **Rencanakan kurva** sebagai peluang, bukan angka mentah:
   ```js
   // peluang 1 percobaan terarah mencapai bintang 1 / 2 / 3
   const base = Math.max(0.93 - (chapter - 1) * 0.026, 0.42); // bab 1 ~93% turun ke ~45%
   p1 = kind === 'bonus' ? 0.92 : kind === 'boss' ? base - 0.14 : base - index * 0.03;
   p2 = p1 * 0.5;
   p3 = Math.max(0.07, p1 * 0.2);
   ```
4. **Generator memilih ambang dari distribusi.** Untuk tiap level jalankan ±240 percobaan pada papan yang persis sama, urutkan hasil, ambil kuantil: `target = q(pops, p1)`, `s2 = q(pops, p2)`, `s3 = q(pops, p3)`. Simpan ke `js/levels-data.js` dengan header "Generated by scripts/gen-levels.js. Do not edit by hand."
5. **Kurasi papan.** Dari 4 kandidat seed per level, pilih yang hasil tipikalnya (median) paling "juicy", lalu ambang menjaga kesulitan sesuai rencana.
6. **Bos / parameter lain** (HP, waktu, jumlah langkah): cari nilai yang peluang menangnya paling dekat dengan rencana.
7. **Ukur ulang dengan seed berbeda** (`audit-stars.js`) dan tulis tabel "sesudah". Kalau meleset, ubah rencana, bukan angka per level.
8. **Setiap perubahan konstanta engine** (radius ledakan, kecepatan, ukuran papan) wajib diikuti menjalankan ulang generator.

## Ritme dan struktur

- **Gigi gergaji**: 10 level per bab. Level 1-4 naik, 5 bonus (napas), 6-9 naik, 10 bos. Bab baru mulai sedikit lebih mudah dari akhir bab sebelumnya.
- **Satu mekanik baru per bab** di awal (Bom, Pembelah, Es, Baja, Hantu, Magnet), diperkenalkan dengan banner, lalu dikombinasikan.
- **Bintang dari distribusi, bukan dari "semua"** (bukan "habiskan semua gelembung") supaya bintang 3 selalu menantang tapi mungkin.
- **Gerbang bintang** antar bab: `ceil((bab - 1) * 30 * 0.55)` bintang. Memberi alasan mengulang level lama.
- **Tingkat kesulitan tetap** (Onet) memakai tabel di `js/levels.js`: ukuran papan, jumlah jenis gambar, waktu, petunjuk/acak, pengali skor, mekanik per babak. Tabel yang sama dipakai game dan tes.
- **Bintang dari waktu** (Onet): >= 50% sisa waktu = 3, >= 25% = 2, sisanya 1. Jelaskan di layar: "Makin cepat selesai, makin banyak bintang".
- **Mode**: Santai (tanpa tekanan), mode berbatas waktu (Kilat: 75 detik, tiap aksi memotong waktu, aksi bagus menambah waktu), mode aturan khusus (Gelas: kalah kalau tumpah). Simpan rekor per mode.

## Perintah standar (contoh LETUP!)

```sh
node scripts/gen-levels.js 240             # hitung ulang semua level (~4 menit)
node scripts/gen-levels.js 240 1 200 --boss
node scripts/audit-stars.js 100            # verifikasi peluang bintang per bab
```
